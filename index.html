The data

Where the catalogue comes from

The Vault reads its listing live from the juicevault archive API on every load, so the counts on the page are whatever the archive holds right now rather than a number typed in by hand. If that request fails or times out, the page falls back to a small sample bundled with the site and says so in the header.

  • Titles, alternate names, duration, category, file size, archive date and play count.
  • Cover images, loaded straight from the archive.

Alternate titles

1,499 entries circulate under more than one name, so search covers those too. It is the field the whole page is designed around.

Six categories

Main, instrumental, stem, cut, released and remaster, each filterable and colour coded.

Loaded in batches

Sixty cards at a time as you scroll. Putting all 3,879 in the page at once would not be usable.

The covers

Artwork where it exists, generated where it does not

2,073 entries carry their own artwork and every one of those images is distinct. The rest share a single generic placeholder per category, which looks repetitive very quickly, so anything without real artwork gets a cover generated from its title instead.

There are eight compositions and sixteen palettes. The layout, the mark, its size and position all change between them, so these are eight different designs rather than one design in eight colours. A title always produces the same cover, and the compositions are dealt out evenly so no two entries share both a composition and a palette.

The build

How these pages were put together

Both pages share one design system: a dark ground that stays close to neutral so the artwork carries the colour, Righteous for display type, Poppins for interface text and JetBrains Mono for anything numeric that needs to line up. The palette, type pairing and page patterns came out of the ui-ux-pro-max design skill and were then adjusted to fit the subject.

Split into modules

Config, helpers, API, cover art, rendering, lightbox and the entry point are separate files, so the one place that touches the network is easy to check.

Fails softly

The catalogue request times out rather than hanging, a cover that will not load falls back to a generated one, and a stalled image cannot stop the page.

Keyboard and motion

Focus is trapped in dialogs and handed back on close, "/" jumps to search, and every animation stops under reduced motion.

No build step

Plain ES modules and plain CSS, served as files. There is no bundler, no framework and no dependency to install.
